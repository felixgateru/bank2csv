# 0002 — Changes made while implementing v0.1

- Date: 2026-11-13
- Status: Accepted
- Amends: [0001](0001-initial-architecture.md)

## Context

The first real statement was an I&M Bank (Kenya) emailed PDF: 3 pages, iText,
AES-128 (`/AESV2`, R4), Lato CID fonts, objects packed in compressed object streams.

## Decisions

1. **Decrypt during load, not after.** Loading with `lopdf` and then calling
   `decrypt()` silently loses every object stored inside an encrypted object
   stream. The pages then contain no text, and we reported `NEEDS_OCR` on a text
   PDF. We now load once without a key to check for encryption, then reload with
   `LoadOptions::with_password`. A document that is still marked encrypted after
   that is reported as `WRONG_PASSWORD` (or `ENCRYPTED` if no password was given).

2. **The table-recovery layer lives in `core::layout`, not in `extract`.**
   Column definitions are bank-specific, so each parser calls the layer with its
   own header specs. Keeping it in `core` means fixture tests never compile or
   run the PDF engine.

3. **Columns are matched by alignment edge, not fixed x-bands.** Each column is
   anchored on its header and declared left-, right- or center-aligned. A span
   goes to the column whose matching edge is closest. In the I&M layout, amounts
   end exactly at their header's right edge, while balances overhang theirs by
   about 11pt. Edge matching handles both without per-bank tuning.

4. **Printed control totals belong in the model.** `Statement.total_debits` and
   `total_credits` are checked by the shared validator (`TOTALS_MISMATCH`).
   v0.1 first checked them inside the I&M parser, which made a misread amount
   surface as `PARSE_FAILED` and bypassed `lenient` mode.

5. **Committed fixtures are synthetic.** Hand-anonymising a real statement is
   error-prone, because names and phone numbers also appear inside narratives.
   Instead, a committed generator (`tools/fixtures/`) reproduces the layout's
   coordinates and quirks with invented data. Real statements are only used
   through the git-ignored private end-to-end test.

6. **Dev CLI crate.** `crates/cli` provides `dump`, `convert`, `parse-raw` and
   `banks`. It reads passwords from a file or an environment variable, never
   from argv.

7. **CSV formula-injection guard.** Text cells starting with `=`, `+` or `@`
   (or `-` when not a number) are prefixed with `'` and quoted.

## Consequences

- Binary size is 1.07 MB, or 505 KB gzipped, after `wasm-opt -Oz` (1.48 MB /
  565 KB before it); `pdf-extract`
  and `lopdf` dominate. If size matters later, the alternative from 0001 still
  stands: let the host extract spans with pdf.js and accept `RawDocument` JSON.
- Not verified yet: AESV3 (AES-256) statements, `Dr` (overdrawn) balances in the
  I&M layout, and statements whose wrapped narrative crosses a page break.
